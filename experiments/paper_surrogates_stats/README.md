# Paper 3: Surrogates-Based Statistical Testing on Graph

## Title

Signal Processing on Directed Graphs: Advection-Diffusion Framework

## Authors

- Chun Hei Michael Chan (EPFL - MIPLab)

## Summary

This paper introduces a framework for signal processing on directed graphs using the advection-diffusion operator. The advection-diffusion operator combines drift (advection) and spread (diffusion) dynamics, making it particularly suitable for modeling asymmetric processes on networks.

Key contributions:
1. Formulation of the advection-diffusion operator for directed graphs
2. Spectral analysis and graph Fourier transform based on the operator
3. Applications to filtering and signal denoising on directed networks
